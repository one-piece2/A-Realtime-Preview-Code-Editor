## 🔧 需要修复的问题

### 问题 1：GitHub Scope 错误

**当前代码：**
```typescript
scope: ['public_profile'], // ❌ 错误！这是 Facebook 的 scope
```

**应该改为：**
```typescript
scope: ['user:email'], // ✅ 正确！GitHub 的 scope
```

**原因：**
- `public_profile` 是 Facebook OAuth 的 scope
- GitHub OAuth 的 scope 应该是：
  - `user:email` - 获取用户邮箱（推荐）
  - `read:user` - 读取用户基本信息
  - 或者两者都加上：`['user:email', 'read:user']`
